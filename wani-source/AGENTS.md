# Wani site workflow

This directory is the Vercel application root in `l1md3en1s-lang/Wani`.
The production branch is `main`, and the production site is
https://wani-psi.vercel.app/.

The site owner has asked for requested site edits to be published as part of
the same task. After editing, run relevant local checks, publish only changed
source files to this directory through the connected GitHub app, and verify
the resulting production deployment. Read the current remote file before
updating it so newer work is not overwritten. Never upload `node_modules`,
`.next`, local environment files, credentials, or build caches.

Report separately when an edit is complete locally, when it is on GitHub,
and when the production site actually shows the change. If publishing or
verification is unavailable, state that clearly.
